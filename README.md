# RepLens — นับวิดพื้นและสควอตด้วยกล้อง

เว็บแอปที่ทำงานใน Safari บน iPhone ไม่ต้องใช้ Xcode ไม่ต้องลงแอป
ตรวจจับท่าด้วยโมเดล MediaPipe Pose ที่รันในเครื่อง ภาพจากกล้องไม่ถูกอัปโหลด
ประวัติการฝึกเก็บในเครื่อง (localStorage)

## วิธีเปิดบน iPhone

Safari อนุญาตให้ใช้กล้องเฉพาะเว็บที่เป็น **https** จึงต้องวางไฟล์ไว้บนโฮสต์ฟรีสักที่หนึ่งก่อน (ทำครั้งเดียว)
การเปิดไฟล์ `index.html` ตรง ๆ จากเครื่อง หรือผ่าน `http://192.168...` ใช้กล้องไม่ได้

### ทางเลือก A: GitHub Pages (ถาวร ฟรี)
1. สมัคร github.com แล้วสร้าง repository ใหม่ (Public) ชื่อ `replens`
2. กด Add file > Upload files แล้วอัปโหลดทุกไฟล์ในโฟลเดอร์นี้ รวมโฟลเดอร์ `icons`
3. ไปที่ Settings > Pages ตั้ง Branch เป็น `main` โฟลเดอร์ `/ (root)` แล้ว Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://ชื่อผู้ใช้.github.io/replens/`

### ทางเลือก B: Netlify Drop
1. เปิด app.netlify.com/drop บนคอมพิวเตอร์ แล้วลากทั้งโฟลเดอร์นี้ไปวาง
2. ได้ลิงก์ https ทันที สมัครบัญชีฟรีเพื่อให้ลิงก์ไม่หมดอายุ

### เปิดครั้งแรก
1. เปิดลิงก์ใน Safari บน iPhone ต่ออินเทอร์เน็ตไว้ (แอปต้องโหลดโมเดลราว 10 MB ครั้งแรก)
2. แตะ "เปิดกล้อง" แล้วเลือก "อนุญาต"
3. แตะปุ่มแชร์ > "เพิ่มลงในหน้าจอโฮม" เพื่อเปิดเป็นแอปเต็มจอ หลังจากนั้นเปิดออฟไลน์ได้

ลองดูหน้าจอก่อนใช้กล้องได้ที่ ตั้งค่า > สาธิตวิดพื้น / สาธิตสควอต

## วิธีตั้งกล้องให้นับแม่น
- **วิดพื้น:** วางมือถือบนพื้นด้านข้างลำตัว ห่าง 1.5–2 เมตร ให้เห็นตัวตะแคงตั้งแต่ไหล่ถึงข้อเท้า
- **สควอต:** วางมือถือระดับเอว ห่าง 2 เมตร หันตัวตะแคงข้างให้กล้อง (มองจากด้านหน้า มุมเข่าจะวัดไม่ได้)
- แสงสว่างพอ พื้นหลังไม่รก เสื้อผ้าไม่หลวมมากจนมองไม่เห็นข้อต่อ
- กด "เริ่ม" จะมีเวลาตั้งท่า 5 วินาที แล้วเริ่มนับ กด "หยุดและสรุป" เมื่อจบเซ็ต แก้ตัวเลขได้ก่อนบันทึก

## วิธีนับ
- วิดพื้น: วัดมุมศอก นับ 1 ครั้งเมื่อศอกงอไม่เกิน 105° แล้วเหยียดกลับเกิน 150°
- สควอต: วัดมุมเข่า นับ 1 ครั้งเมื่อเข่างอไม่เกิน 112° แล้วยืนกลับเกิน 155°
- ถ้าลงไม่ถึงเกณฑ์ จะไม่นับและแจ้งว่า "ลงไม่ลึกพอ"
- แจ้งเตือนท่า: สะโพกตก/สะโพกสูง (วิดพื้น) และตัวโน้มหน้ามาก (สควอต) ครั้งที่มีปัญหาจะไม่นับเป็น "ถูกท่า"
- ปรับเกณฑ์ได้ที่ค่า `CONFIG` ต้นไฟล์ `counter.js`

## ข้อมูลและการสำรอง
- ประวัติอยู่ในเบราว์เซอร์ของเครื่องนั้นเท่านั้น
- Safari อาจล้างข้อมูลเว็บที่ไม่ได้เปิดเกิน 7 วัน และ "หน้าจอโฮม" แยกที่เก็บข้อมูลจากแท็บ Safari
  เลือกใช้ทางใดทางหนึ่งเป็นหลัก แล้วกด ตั้งค่า > ส่งออกไฟล์สำรอง เป็นระยะ
- นำเข้าไฟล์สำรองกลับได้ที่ ตั้งค่า > นำเข้าไฟล์สำรอง (ข้ามรายการที่ซ้ำให้อัตโนมัติ)

## ไฟล์ในโฟลเดอร์
| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html`, `style.css` | หน้าจอ |
| `app.js` | กล้อง การตรวจจับท่า การวาด การบันทึก |
| `counter.js` | วัดมุม ตรวจท่า นับครั้ง (ไม่ผูกกับเบราว์เซอร์ ทดสอบได้ใน Node) |
| `store.js` | บันทึกประวัติ สถิติ ส่งออก/นำเข้า |
| `sim.js` | โหมดสาธิต (ร่างจำลองแทนกล้อง) |
| `sw.js`, `manifest.webmanifest`, `icons/` | ใช้ออฟไลน์และเพิ่มลงหน้าจอโฮม |

ไลบรารีตรวจท่า (MediaPipe Tasks Vision 0.10.21) และโมเดลโหลดจาก jsDelivr และ Google Storage ตอนเปิดครั้งแรก
แล้ว service worker แคชไว้ในเครื่อง

## แก้ปัญหา
- **ขึ้น "ต้องเปิดผ่าน https":** เปิดจากลิงก์ที่โฮสต์ไว้ ไม่ใช่ไฟล์ในเครื่อง
- **ไม่ได้รับอนุญาตใช้กล้อง:** ตั้งค่า > Safari > กล้อง เลือก "ถาม" หรือ "อนุญาต" แล้วรีเฟรช
- **โหลดโมเดลไม่ได้:** ต้องออนไลน์ในครั้งแรก ลองสลับ Wi-Fi/มือถือ แล้วเปิดใหม่
- **ภาพกระตุก:** ใช้โมเดล "เร็ว (เบา)" ปิดแอปอื่น และอย่าให้เครื่องร้อน
- **ไม่นับ:** ดูข้อความบนเวที ส่วนใหญ่คือยังเห็นตัวไม่ครบ หรือยังไม่ได้เหยียดตัวตรงก่อนเริ่ม
